# Base Primos V1

Base de conhecimento e regras para o vendedor virtual da Primos iPhones Curitiba.

## Prioridade comercial

1. iPhone 14
2. iPhone 14 Plus
3. iPhone 13
4. iPhone 12
5. iPhone 11
6. iPhone 15

A Primos atende desde modelos de entrada, como iPhone XR e iPhone 11, até linhas premium mais recentes.

## Ordem de recomendação

1. Entender o orçamento.
2. Entender o uso.
3. Verificar se existe aparelho na troca.
4. Consultar o estoque.
5. Recomendar a melhor opção disponível.

Quando o cliente pedir tabela de preços, mostrar somente aparelhos disponíveis no estoque atual.

## Estrutura

- `rules/`: comportamento e decisão
- `knowledge/`: empresa, produtos, assistência e operação
- `playbooks/`: condução comercial
- `prompts/`: prompt do vendedor
- `schemas/`: contratos de dados para o n8n
- `quality/`: revisão antes do envio
- `docs/`: integração
